# Project Roadmap

This document outlines the milestones, current achievements, and future directions for Sagittarius LogViewer.

## Achieved Milestones (Core Engine & UI)

- **v1.0.0 (Current Baseline)**:
  - Asynchronous background worker using `asyncio` and `QThread`.
  - Multi-stream log ingestion (TCP socket, stdin pipe, file tailing).
  - High-performance logging table and custom highlighting via Qt Model/View.
  - Multi-line buffer and JSON log line parser.
  - Real-time severity stats pie charts and a visual scrollbar Heatmap.
  - Custom bookmarks, search find bar, and detail inspector panel.
  - Full TOML-based configuration (regex format, presets, custom palette) and Settings dialog.
